# injectyou....web

A lightweight task planner web app with realistic daily-use features:
- Task creation with priority and due date
- Status filtering (all, active, completed)
- Completion toggling and item deletion
- Clear-completed action
- Local persistence with `localStorage`

## Run locally
Open `/home/runner/work/injectyou....web/injectyou....web/index.html` in a browser.

## Test
```bash
npm test
```
